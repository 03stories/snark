Agent folder

Lets Claude (or any agent) read and edit Snark through files in a folder you pick, such as ~/Desktop/Snark-data. See AGENTS.md inside it.

Backup

Spaces, folders, pins, favorites and settings as a JSON file. Use it to move to a new folder, profile or computer.

Spaces are turned off. Turn on “Spaces & pinned tabs” in ⚙ settings.
